# Homely

**Your home. Your routine. Your way.**

A Filipino-friendly household routine and home planner designed to make everyday home life easier.

## Current build
- Responsive web app / PWA
- English / Filipino / bilingual UI
- Chores and recurrence
- Rooms
- Calendar
- Progress history
- Cleaning Mode
- Accessibility settings
- Browser notifications permission
- Supabase Auth + cloud sync
- Row Level Security-ready database schema
- MJB developer branding

## Files
- `index.html` — app
- `sw.js` — service worker
- `mjb-logo.png` — MJB branding
- `supabase-schema.sql` — database + RLS setup
- `SUPABASE-SETUP.md` — setup guide
